# Rummaina CipherVault 🛡️

**Rummaina CipherVault** is a privacy-first, zero-knowledge secure utility designed to share confidential text notes and large media files (up to 4GB) safely without leaving digital footprints.

## ✨ Key Features
- **Self-Destructing Notes:** Links designed for secure single-use or reader-controlled burning.
- **Heavy Media Support:** Safely share videos, images, and documents up to 4GB.
- **Zero-Knowledge Architecture:** Complete privacy with no persistent tracking or unauthorized database logging.
- **Pro Features Integration:** Premium tier configuration including password-protected encrypted payloads.
