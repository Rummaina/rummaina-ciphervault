# Rummaina CipherVault 🛡️

**Rummaina CipherVault** is a modern, zero-knowledge secure text and media sharing utility built with speed, user privacy, and high-tech aesthetics in mind. It allows users to send confidential information and self-destructing notes with end-to-end client-side control.

---

## ✨ Key Features

* **Zero-Knowledge Architecture:** Messages and data are encrypted locally before generation, ensuring maximum confidentiality.
* **Self-Destructing Notes:** Readers can securely view payloads and choose to permanently burn or wipe them out forever.
* **Modern Cyberpunk UI:** Designed with a sleek Dark Obsidian and Neon Cyan theme using [Tailwind CSS](https://tailwindcss.com/).
* **Pro Vault Upgrades:** Simulated tier options for monthly and lifetime high-end security expansion.
* **Interactive Feedback System:** Dynamic rating experience with real-time feedback handling.
